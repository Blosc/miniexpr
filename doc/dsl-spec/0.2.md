# Menudet 0.2 — dtype annotations

This incremental language version retains Menudet 0.1 numerical/execution semantics and
adds optional parameter and return dtype annotations. It is implemented in
direct C preparation, source validation and Python author normalization.
Python's new `b2o` v2 records retain annotated source without inferred input
types. It does not introduce a new JSON schema.

```python
def select_reading(word: uint16, reading):
    if (word >> 15) != 0:
        return reading
    return reading * 0
```

The signature must supply `uint16` for `word`, without implicit conversion.
`reading` specializes to its binding's dtype. Inference does not add an author
constraint to saved source.

An optional return annotation such as `-> float64` converts the final output.
It does not widen intermediate operations or reduction accumulation. A
conflicting explicit output dtype rejects; the casting policy still applies.

| Kind | Canonical element dtype names |
| --- | --- |
| Boolean | `bool` |
| Signed | `int8`, `int16`, `int32`, `int64` |
| Unsigned | `uint8`, `uint16`, `uint32`, `uint64` |
| Float | `float32`, `float64` |
| Complex | `complex64`, `complex128` |

No qualified names, arbitrary annotation expressions, local declarations,
`auto`, shapes or fixed-string annotation syntax are admitted. Unannotated
fixed-string bindings retain their byte widths in signature metadata.

Python authoring translates resolved types such as `np.uint16` to canonical
`uint16`, never copy a Python module alias into portable source. The native
parser maps that spelling to `ME_UINT16`. A captured parameter can be annotated:
the declared dtype makes an otherwise weak capture strong and must match its
native representation.

Unannotated 0.2 retains 0.1 promotion, scalar categories and return-join rules.
In particular, annotation support does not add weak-branch type joins:
the example uses `reading * 0` so both return paths have `reading`'s type,
rather than the existing join with a separate integer `return 0`.

Version selection is explicit. Version 0.1 continues to reject annotated source,
including in existing JSON artifacts. The old full-DSL profile is not 0.2.
